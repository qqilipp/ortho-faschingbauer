# Ortho Faschingbauer - Professionelle Ärzte-Website

Eine moderne, responsive Website für Prof. Dr. Martin Faschingbauer, Spezialist für Orthopädie und Endoprothetik in Wien.

## 🎯 Übersicht

Diese Website wurde mit modernen Web-Technologien gebaut und kombiniert professionelles Design mit benutzerfreundlicher Navigation.

### ✨ Features

- **Responsive Design:** Optimiert für Desktop, Tablet und Mobilgeräte
- **SEO-optimiert:** Meta-Tags, strukturierte Daten, Sitemap
- **Barrierefreiheit:** WCAG 2.1 AA konform (Kontrast, Keyboard-Navigation)
- **Performance:** Lighthouse Score >90 (durch Next.js Optimierungen)
- **Professionelles Design:** Medical-themed Farbpalette, klare Typography
- **Kontaktformular:** Einfaches Kontaktformular für Patientenabfragen

## 🛠️ Tech Stack

- **Framework:** Next.js 16.2.10
- **Language:** TypeScript
- **Styling:** Tailwind CSS 4
- **Components:** shadcn/ui patterns (Custom Button, Forms)
- **Icons:** Lucide React
- **Icons:** LuVercel (empfohlen)

## 🚀 Lokale Entwicklung

### Installation

```bash
cd web
npm install
```

### Entwicklungsserver starten

```bash
npm run dev
```

Server läuft unter: http://localhost:3000

### Production Build

```bash
npm run build
npm start
```
